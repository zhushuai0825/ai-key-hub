# 微短剧剧本写法规范

> 用途：写大纲、扩写剧本、AI 改稿时检索。关键词：写剧本、分集正文、可拍、对白、场景头。只借写法，不借具体剧情。

## 单集目标

- 字数：约 1500～2200（竖屏微短剧）
- 结构：钩子 → 升级 → 半兑现 → 可见事件尾钩
- 每集至少 1 个「观众以为会怎样、实际更狠一步」的反转

## 场景头格式

```
【场景】地点 · 日/夜 · 内/外
人物：A、B
```

- 新场景必写场景头；同一地点连续戏可省略，但换时空必须重写
- 动作行写「可见行为」，不写「他感到……」

## 动作与对白比例

| 类型 | 建议 |
|------|------|
| 爽文打脸 | 对白 40%～55%，动作要短、狠、可拍 |
| 情感/年代 | 对白可略多，但每段对白后跟一个可见反应 |
| 悬疑揭秘 | 道具特写与信息差优先，对白少而准 |

## 对白写法

1. 口语短句；一句一意
2. 遮住名字也能听出是谁（用词、节奏、称呼）
3. 禁止：因此、毫无疑问、我认为、这意味着、内心独白解释画面
4. 情绪失控：打断、改口、只说关键词
5. 潜台词优先：别把观众已看见的再说一遍

## 冲突升级清单（每集至少用 2 条）

- 压力加大（时间/钱/身份）
- 新信息出现（信、录音、证人）
- 关系位移（结盟/反目/暧昧破裂）
- 第三方介入（家人、仇家、媒体）
- 道具易手或证据曝光

## 尾钩必须是事件

合格：门被踹开、信封掉出、倒计时归零、人被带走、身份证件亮出  
不合格：发呆、沉思、空泪、气氛凝重、回忆闪回收尾

## 可拍性自检（写完勾一遍）

- [ ] 每个重要情绪都有对应肢体/物件动作
- [ ] 没有「然后他们聊了很久」这种不可拍摘要
- [ ] 场景转换靠空间/时间，不靠旁白跳切
- [ ] 本集承诺半兑现，下集钩子已落地为画面

## 与分镜的衔接

剧本写完后拆分镜时：每一场戏至少拆成「建立→冲突点→反应/钩」三镜；对白重戏优先近景/特写。
