# 竖屏分镜提示词规则（漫剧/微短剧）

> 用途：写分镜、写 Seedance/即梦视频 prompt 时检索。只借规则，不借具体剧情。

## 单镜万能公式

```
主体 + 动作 + 环境/光线 + 镜头运动 + 风格约束
```

中文约 80～150 字；单镜只写一个核心动作。

## 五条铁律

1. **每镜只给一个主运镜**：推、拉、摇、跟、环绕、手持、固定，选一个最重要的。
2. **镜头动作和人物动作分开写**：「她慢慢回头。镜头保持固定中景」优于「镜头环绕转身的她」。
3. **用节奏词不用技术参数**：写「缓慢、流畅、稳定」，不写「24fps / f2.8 / 85mm」。
4. **动作必须可见**：写「攥紧信封、抬眼看门口」，不写「她感到不安」。
5. **禁止空词**：电影感、氛围感、高级感、震撼、绝美、充满张力 → 改成具体画面因果。

## 竖屏景别习惯（9:16）

| 景别 | 何时用 |
|------|--------|
| 大特写/特写 | 情绪、关键道具、悬念（竖屏主力） |
| 近景 | 重要对白、表情转折 |
| 中景 | 双人对话、日常互动 |
| 全景/远景 | 新场景建立，少用 |

近景+特写合计建议占 50%～65%；同景别连续不超过 2～3 镜。

## 运镜词典

| 中文 | 英文/常用写法 | 效果 |
|------|---------------|------|
| 缓慢推镜 | slow push-in / dolly in | 强调细节、压迫、情绪升级 |
| 拉远 | pull-out / pull-back | 揭示环境、孤立感 |
| 横摇 | pan left/right | 扫视空间 |
| 跟拍 | tracking shot | 行走、追逐、跟角色 |
| 环绕 | orbit / arc shot | 对峙、商品展示 |
| 升降 | crane up/down | 开场俯瞰、结尾升华 |
| 手持 | handheld | 紧张、临场、纪录片感 |
| 固定 | locked-off / static | 让主体动作承载张力 |

## 多镜头时间轴写法（12～15 秒）

```
[0:00-0:04] 近景，女主手握信封，侧光轮廓，固定镜头。
[0:04-0:08] 中景，她抬头看向门口，缓慢推镜，暖色室内光。
[0:08-0:12] 过肩全景，门口站着男主，逆光剪影，手持轻微晃动。
```

## 负面约束（可附在 prompt 末尾）

避免：抖动、肢体扭曲、人脸变形、文字乱码、服装突变、多余手指、画面闪烁。

## 已验证模板

**对峙推镜**
> 中景，两人隔桌对峙，女主缓慢放下杯子，杯底磕桌有声。镜头缓慢推近女主面部，顶侧光，阴影压眼，竖屏 9:16，画面稳定，面部清晰不变形。

**图生视频（锁脸锁服装）**
> 基于参考图保持人物样貌与服装一致。角色缓慢抬手把碎发别到耳后，自然眨眼，微风拂动衣角。固定中景，窗边暖光，丝滑连贯，无抖动。
