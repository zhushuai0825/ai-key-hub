# Seedance中文提示词句式

> 用途：生成/润色视频分镜提示词。只借句式结构，角色与剧情须换成当前项目原创设定。

## 万能骨架（单镜）

```
[@图片N 作为角色/场景参考]
主体 + 一个主动作 + 环境光影 + 景别 + 单一运镜 + 竖屏9:16 + 电影质感4K + 面部清晰不变形
```

中文约 80～150 字；一镜一动。

## 安全句式模板（换皮使用）

**人物戏：**  
`原创角色站在狭窄走廊，缓慢放下信封，目光停在紧闭的门上。稳定中近景轻微推进。暖色顶灯微闪，墙面有冷色雨光。`

**动作：**  
`原创角色雨夜屋顶奔跑，跃过狭窄缝隙，落地单膝撑住冲向铁门。低机位手持跟拍，冷色灯与湿滑地面反光。`

**对白口型：**  
`原创角色坐在桌前，固定中近景。头部稳定，仅轻微表情变化。短对白口型清晰。柔和侧窗光，背景暖台灯。`

**首尾帧：**  
`@图片1为首帧，@图片2为尾帧。保持同一角色服装与房间布局，从椅子缓慢站起到窗边停在尾帧姿势。动作连续不跳切。固定中景轻推。`

**续写上段：**  
`从已接受视频真实结尾继续：角色仍停在原姿势与道具位置。本段只做一个新动作，不重复上段已完成动作，不提前剧透下段。`

## 多参绑定

- 有定妆图：开头写 `@图片1 作为角色参考`
- 有场景图：`@图片2 作为场景参考`
- 只借运镜参考视频：写明「仅参考运镜节奏，不复制人物场景品牌」

## 禁止

- 一镜多运镜叠加
- 空词：电影感、高级感、充满张力（无具体光与动作）
- 点名真人/IP/品牌；改为原创描述特征
- 情绪词不落地（「心痛」→「指甲掐进掌心」）
