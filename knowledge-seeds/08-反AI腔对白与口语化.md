# 反AI腔对白与口语化

> 用途：写剧本、AI 改稿时检索。让对白像「这个人在这个压力下不得不说的话」。

## 三问（写完逐句过）

1. 遮住名字，还能听出是谁吗？
2. 表面说 A，真实意图是 B 吗？（有潜台词）
3. 这句是在推进冲突/关系，还是在解释观众已看见的画面？

## 高风险书面词（冲突场默认改掉）

| 写法 | 改法 |
|------|------|
| 因此 / 所以 / 毫无疑问 / 更何况 | 命令、反问、判断、动作 |
| 我认为 / 我觉得 / 从某种角度 | 直接说利益、威胁、证据 |
| 这说明 / 这意味着 / 由此可见 | 用证据逼对方自己得出结论 |

正式场合（法庭、发布会、授课）可保留部分书面词，但须符合身份。

## 情绪失控时的语言

应变短、重复、断裂、抢话、改口或只吐关键词；禁止崩溃时仍说完整长句。

- 短句压迫：「说。谁让你来的。」
- 有效重复：每重复一次必须加新压力或新信息
- 打断：用对方插话或动作打断，不用破折号

## 无意义重复（删）

- 同义词连问两遍无新压力
- 解释观众已看见的画面
- 「你说什么/你再说一遍」纯拖时长

## 声音指纹（角色卡可另建文档）

每个主角写清：句长倾向、说话路径、常用称呼、撒谎躲闪方式、失控时怎么说话、绝不会说的句式。
