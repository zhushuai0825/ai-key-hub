# 角色声线卡与对白规则

> 用途：写剧本、改稿、提取角色时检索。每个主角/反派建议单独再建一篇「角色名·声线卡」。

## 声线卡模板（复制后填空）

```
角色名：
身份/欲望：
说话习惯：（短句/长句/爱打断/爱反问/少废话）
口头禅：（1～2 个，不要多）
压力下：（语速变快/变短/只吐关键词/冷笑）
对他人的称呼差：（对 A 叫全名，对 B 只叫姓）
禁忌词：（不会说的书面腔）
示例对白 1：（8～15 字，带动作）
示例对白 2：（带潜台词，不解释画面）
```

## 对白铁律

1. **遮住名字也听得出是谁**：用词、节奏、称呼、打断方式要不同。
2. **一句一意**：能拆成两句就别挤成一句。
3. **潜台词 > 解释**：观众已看见的不说第二遍。
4. **情绪用动作托**：攥拳、停半秒、改口，而不是「他很愤怒」。

## 竖屏短剧常见角色声线差

| 类型 | 说话特征 |
|------|----------|
| 强势压迫型 | 短句、命令式、少解释、爱反问 |
| 隐忍反击型 | 平时短、关键时刻只说一句狠的 |
| 外柔内狠型 | 表面客气，关键词突然变硬 |
| 喜剧缓冲型 | 吐槽、跑偏、用具体物件打比方 |
| 信息掮客型 | 半句留半句，逼对方追问 |

## 改稿指令示例（给 AI 改稿用）

- 「把这段对白压到每句 12 字以内，更像口语」
- 「A 更冷更短，B 更碎更急，两人节奏拉开」
- 「删掉解释画面的句子，只留动作+对白」
- 「结尾换成可见事件钩，不要发呆收尾」

## 反 AI 水词替换

| 别写 | 改成 |
|------|------|
| 气氛瞬间凝固 | 屋里没人说话，只听见空调声 |
| 他感到一阵寒意 | 他后颈起了一层鸡皮疙瘩 |
| 眼神复杂 | 他看她两秒，把话咽回去 |
| 充满张力 | 两人相距一步，谁都没先动 |
