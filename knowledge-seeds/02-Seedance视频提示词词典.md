# Seedance 2.0 视频提示词词典

> 用途：即梦/Seedance 单镜与多参生成。检索关键词：Seedance、即梦、视频 prompt、运镜、I2V。

## 六步结构

1. **主体**：谁/什么，2～3 个稳定视觉特征（服装、发型、年龄感）
2. **动作**：一个主动作 + 节奏（缓慢/突然/连贯）
3. **环境**：地点、时间、天气、可见道具
4. **镜头**：只写一个主运镜 + 景别（特写/中景/全景）
5. **风格**：电影质感、纪实、广告棚拍、古风等，只选一个主风格
6. **约束**：avoid 抖动、变形、闪烁、多余肢体

## 长度建议

- 单镜：60～100 词（中文约 80～150 字）
- 多镜头叙事：可按时间段写到 300 字，但每段仍只一个主运镜

## 多参 @ 引用写法

```
@图片1 作为角色参考
@图片2 作为场景参考
中景，角色站在窗边低头看手机，手指轻滑屏幕，窗外斜阳照在脸上，固定镜头，电影质感，4K，面部清晰不变形
```

## 镜头与主体分离（最重要）

- ✅ 她慢慢转身面向门口。镜头保持固定中景。
- ❌ 镜头环绕着一个转身的女人。（容易人物和镜头一起乱转）

## 一动原则

每镜一个核心动作。连续动作拆成多镜：

- ✅ 她猛地转身，眼中含泪
- ❌ 她转身、摔杯、冲出门（拆 3 镜）

## 常用运镜英文（模型识别好）

- slow push-in / dolly in
- pull-back / pull-out
- pan left / pan right
- tracking shot
- orbit / arc shot
- crane up / crane down
- handheld
- locked-off / static shot

## 光线词（高杠杆）

- 黄金时刻侧光、窗边暖光
- 顶光压眼、轮廓逆光
- 冷蓝夜景、霓虹反射
- 柔光漫射、阴天平光

## 竖屏短剧推荐组合

| 场景 | 景别 | 运镜 | 备注 |
|------|------|------|------|
| 开场钩子 | 近景→特写 | 快推 | 前三秒给冲突物件或表情 |
| 对峙 | 中景 | 慢推 | 人物占画面 70% |
| 揭秘 | 特写 | 固定 | 道具/眼神/手机屏 |
| 追人 | 中景 | 跟拍 | 手持可加紧张感 |
| 结尾钩 | 近景 | 固定或轻推 | 停在「下一秒要发生」的动作上 |

## 避免

- 一镜多运镜叠加（推+摇+环绕）
- 写「 cinematic / 电影感」但不给具体光与动作
- 超长形容词堆叠
- 让模型同时猜剧情背景和镜头语言
